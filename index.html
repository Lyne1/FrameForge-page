Core idea

Image generation through adaptive virtual temporal relations.

Video models learn visual transformations across time. Conditional image-generation tasks also require different degrees of change between the condition and the target.

FrameForge models these changes as input-adaptive virtual temporal relations, using video priors to accommodate differences across tasks and individual inputs.

Multi tasks. One shared model.

Overview

Abstract

Unified conditional image generation requires a single model to preserve different aspects of a visual input while producing a target image that follows textual guidance. Pretrained video models provide a promising foundation by encoding visual transformations across time, yet existing approaches typically assign the condition and target to fixed temporal positions. We observe that condition-target relationships vary substantially across generation tasks, while video models naturally encode visual transformations at different temporal scales. This motivates us to model conditional generation through input-adaptive virtual temporal relations.

We propose FrameForge, which captures two complementary aspects of such relations. Mixture of Temporal Experts (MoTE) models how far the target lies from the condition by dynamically selecting temporal RoPE experts with different virtual intervals. Chain of Temporal Reasoning (CoTR) models how the condition is transformed into the target through a latent intermediate state, with a reasoning-bottleneck attention mask encouraging information propagation through this pathway. Experiments on DreamBench, COCO2017, and GEdit-Bench show that FrameForge achieves superior performance in subject-driven generation, Canny-to-image generation, and image editing among the compared methods.

The approach

Learn how far, and how, an image should change.

Treat the condition and target as frames in a virtual video.
Adapt their temporal relation to the input and the denoising step.

01 / MoTE

Choose the temporal relation.

A lightweight router selects one of three temporal RoPE experts. Short, medium, and long virtual intervals provide different transformation priors, using equivalent video-frame spans of 17, 69, and 121.

02 / CoTR

Build an intermediate pathway.

One noise-initialized reasoning latent connects the condition to the target. A reasoning-bottleneck attention mask encourages this pathway during intermediate training; inference uses full attention.

Inside the model

The temporal relation evolves as the image emerges.

Expert selection responds to both the task and the denoising stage.

Canny-to-image generation predominantly selects the long-interval expert. Subject-driven generation and editing initially favor the medium interval, then shift toward the short interval as target content emerges. Editing makes this transition earlier and more strongly.

Get started

Generate your own images.

The inference release uses three temporal experts, one reasoning latent,
and a shared LoRA with rank and alpha 32.

Install the code and download checkpoints+

The FLUX.1-Redux-dev repository requires access approval on Hugging Face. Install a PyTorch build compatible with your CUDA environment, then run:

git clone https://github.com/Lyne1/FrameForge.git
cd FrameForge
python -m pip install -r requirements.txt

python -m pip install modelscope

hf download tencent/HunyuanVideo-1.5 --local-dir ./ckpts
hf download Qwen/Qwen2.5-VL-7B-Instruct --local-dir ./ckpts/text_encoder/llm
hf download google/byt5-small --local-dir ./ckpts/text_encoder/byt5-small
modelscope download --model AI-ModelScope/Glyph-SDXL-v2 --local_dir ./ckpts/text_encoder/Glyph-SDXL-v2
hf download black-forest-labs/FLUX.1-Redux-dev --local-dir ./ckpts/vision_encoder/siglip
hf download lyneeeeeeeee/FrameForge pytorch_lora_weights.safetensors --local-dir ./checkpoints

Run inference

Full instructions ↗

Run from the repository root. Replace the input path and prompt. Prepare reference and condition images at 512 × 512; the generated output is also 512 × 512.

bash · Guidance scale 6.0 (default)
CUDA_VISIBLE_DEVICES=0 MODEL_PATH=./ckpts bash scripts/infer.sh \
  --lora_path ./checkpoints/pytorch_lora_weights.safetensors \
  --input_image ./inputs/subject.png \
  --reference_size 512 \
  --prompt "A photo of the same dog playing on a beach" \
  --output_path ./outputs/subject.png \
  --num_inference_steps 50

The launcher selects the 720p video backbone; image-generation output remains 512 × 512.
